# Procurement handoff for review

This directory is an isolated procurement pilot. Its source is not imported
by the main UniAgent runtime. The five implemented procurement rules and their
supporting evidence checks are here for review before integration. Four more
rule topics are proposals in docs/HANDOFF_STATUS.md, not implemented code.

The 8/8 result after the final stage fix reuses saved GPT answers on eight
development cases. It is not a fresh model run, a hidden-set result, or a
verified end-to-end run under 300 seconds per case. Raw traces, model data,
replay scripts and credentials are intentionally not included in this branch.
